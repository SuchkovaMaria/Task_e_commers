# Домашнее задание (создание интернет магазина)

## Описание:

Данный проект разрабатывался в рамках домашней работы и содержит следующий функционал:
1. созданы классы Product и Category;
2. созданы дочерние классы Smartphone и LawnGrass для Product;
3. создан базовый класс (используется как родительский для Product);
4. создан миксин-класс для вывода в консоль информации по параметрам новосозданного экземпляра класса (используется как родительский для Product);


## Установка:

1. Клонируйте репозиторий
   (`git clone`) [GitHub](https://github.com/SuchkovaMaria/Task_e_commers)
2. Установите зависимости
   (`pip requirements.txt`)


## Использование:

1. Откройте проект.
2. Введите данные, запрашиваемые функциями.
